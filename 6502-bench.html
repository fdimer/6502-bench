Clicking φ0 pulses one clock, which is one bus cycle: the 6502 reads or writes memory on every cycle. /IRQ is level-sensitive and masked by the I flag; /NMI and /SO trigger on a falling edge. Holding RDY low stops the CPU on its next read cycle (writes still complete, as on the NMOS part). /RES low holds the CPU in reset; releasing it runs the 7-cycle reset sequence and loads PC from FFFCh.

Program

Standard 6502 syntax, one instruction per line. Labels start in the first column or end with :; comments start with ;. Directives (dot optional): .org or * =, = or EQU, .byte, .word, .res, .end. Numbers: $1F, %1010, 42, 'A'; * is the current address; <label and >label give its low and high byte. Zero-page addressing is used automatically when the address is known to be below 0100h. Code starts at the Load at address; an .org in the source overrides it. Import a file with the button or by dropping it on the editor.

Hex bytes separated by spaces or newlines. Text after ; is ignored. Write FFFA: to continue loading at another address. Intel HEX files (lines starting with :) are also accepted and keep their own addresses. Raw binary ROM images (.bin, .rom) import here as hex. System memory map

The defaults follow a common hobby layout: 16 KB RAM at 0000h, a 6522 VIA at 6000h and ROM from 8000h to FFFFh, which holds the NMI, reset and IRQ vectors at FFFA–FFFFh. The 6502 has no separate I/O space, so peripherals sit in the memory map.
